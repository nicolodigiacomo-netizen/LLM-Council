How to Send to Your Kindle

Method 1: Email (Recommended)

  1. Download the EPUB file below
  2. Email it as an attachment to your Kindle email address
  3. Your Kindle email looks like: yourname@kindle.com
  4. Find it at: Amazon Account → Content & Devices → Preferences → Personal Document Settings
  5. The document will appear on your Kindle within minutes

Method 2: Send to Kindle App

  1. Download and install the "Send to Kindle" app from Amazon
  2. Download the EPUB file below
  3. Right-click the file → Send to Kindle

Method 3: USB Transfer

  1. Connect your Kindle to computer via USB
  2. Download the EPUB file below
  3. Copy the file to the "Documents" folder on your Kindle
  4. Safely eject and disconnect
💡 Tip: EPUB format works best with newer Kindles. If you have an older Kindle, use the PDF option or convert EPUB to MOBI using Calibre software.

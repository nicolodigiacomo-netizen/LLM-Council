How It Works

Share your topic, bullet points, or rough notes. The skill asks about purpose and audience.

What You Get

A single, self-contained HTML file with everything inlined.

<!-- One file. Zero dependencies. -->
<html lang="en">
  <head>
    <!-- Fonts, CSS variables, all styles inline -->
    <style> /* themes, animations, responsive */ </style>
  </head>
  <body>
    <section class="slide">
      <h1 class="reveal">Your Content</h1>
    </section>
    <script> /* navigation, animations, interactions */ </script>
  </body>
</html>

Design Philosophy

  • You don't need to be a designer. You just need to react to what you see. Visual exploration beats abstract choices.
  • Dependencies are debt. A single HTML file works in 10 years. A React project from 2019? Good luck.
  • Generic is forgettable. Every presentation should feel custom-crafted, not template-generated.
  • Comments are kindness. Code explains itself to future-you, or anyone else who opens it.
